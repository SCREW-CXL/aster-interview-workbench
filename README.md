# Aster 面试工作台

Aster 是一款 Windows 面试准备工具，提供语音转写、DeepSeek 回答、个人资料参考、简历建议和面试复盘。

## 下载与使用

1. 从 [Releases](https://github.com/SCREW-CXL/aster-interview-workbench/releases/latest) 下载 Windows x64 安装程序并运行。
2. 打开设置，填写自己的 DeepSeek API Key 并选择模型。DeepSeek API 费用由服务商按实际用量收取。
3. 按需添加简历或项目资料，开始模拟问答；系统声音和麦克风分别记录面试官与自己的发言。
4. 在回答流中查看建议，结束后可以查看复盘和简历改进意见。

安装程序自带标准本机语音模型，无需自行安装 Python。语音识别可能出错，请核对内容；启用个人资料参考时，相关内容会发送至所配置的模型服务。

## 反馈

使用中遇到问题，可通过本仓库的 Issues 提交。请勿在公开内容中填写 API Key、简历、录音或其他个人信息。
